## What the Game Offers

Block Miner Clicker is a pixel-art clicker experience centered on breaking blocks and turning gathered resources into stronger mining output. Players can improve their pickaxe, apply enchantments, build click combos, and deploy miners that continue producing resources automatically.

The progression system includes ranks with permanent bonuses and rare collectibles to discover. Procedural Web Audio API sounds, particle effects, and screen shake reinforce important actions. The layout adjusts to desktop, tablet, and mobile screens, while `localStorage` keeps progress in the current browser environment.

## Gameplay Systems

There is no separate command-line configuration. Progress is managed through the in-game systems below:

| System | Purpose |
|---|---|
| Mining clicks | Break blocks and collect resources |
| Combo meter | Measure uninterrupted mining actions |
| Pickaxe upgrades | Strengthen the current mining setup |
| Enchantments | Provide additional pickaxe progression choices |
| Automatic miners | Produce resources passively |
| Ranks | Add permanent progression bonuses |
| Collectibles | Record rare discoveries made during gameplay |
| Browser save | Preserve progress with `localStorage` |

Saved progress is tied to the site data available to the active browser and browser profile.

## Frequently Asked Questions

### How can I begin playing?

Open the [latest build](https://millerfelixbne9422.github.io/block-miner-clicker-hub/) in a browser with JavaScript enabled and click the block area to start collecting resources.

### Where does the game keep save data?

Progress is saved locally through browser `localStorage`. The save belongs to the specific browser and site context used to play.

### Is progress shared between devices?

No. Local browser storage does not automatically synchronize between devices or browser profiles, so a different environment may have its own separate save.

### How do I receive updates?

Open the published build again to access the current version. A browser refresh may be needed if cached files or existing site data prevent the update from appearing immediately.

### Can I modify the game?

The project uses HTML and JavaScript, and its source can be reviewed or changed under the project license. Modifications may alter gameplay, progression, visuals, or saved data.

### What devices can run it?

The interface is designed for browser use on mobile phones, tablets, and desktop computers. Results may differ depending on the browser, screen dimensions, and available browser capabilities.

### What if I delete my browser data?

Removing the game's site storage may erase the local save. Check the impact on your progress before clearing browser data associated with the game.
